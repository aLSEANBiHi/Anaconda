# todoapp-php

Gravação mostrando a versão atual em uso.

Também existe uma demonstração narrada em inglês.


# Instalando

Depois de clonar o repositório, rode na raiz:

```
composer install
```

Em seguida ajuste os dados de conexão do banco no arquivo de configuração do projeto.

Com o banco configurado, aplique as migrações:

```
php artisan migrate
```


# Executando

```
php artisan serve
```
